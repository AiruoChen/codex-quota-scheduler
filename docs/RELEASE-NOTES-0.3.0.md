# Codex Quota Scheduler 0.3.0 版本说明

本版本增加统一的 Windows x64 桌面验收报告、安装包与源码提交绑定、发布文件逐项 SHA256 校验、候选版自动门禁和稳定版人工证据门禁。桌面客户端继续提供任务、队列、记录、异常处理、托盘与通知；安装器支持当前用户安装、明确迁移、升级前备份和卸载保留数据。

自动验收使用模拟额度和 Codex 协议替身，包含打包 GUI、后台生命周期、隔离安装迁移以及运行观测。默认不访问真实账户，也不执行个人任务。请查看随包的 `report.md` 和 `report.json`，确认每项实际结果、来源提交、安装器 SHA256 和实际运行时长。

稳定版发布要求预期发布者签名与时间戳、独立 Windows 环境、连续 24 小时运行、真实账户的明确授权测试，以及原生通知、显示缩放、故障恢复和 P0 使用流程人工验收。发布渠道以经过门禁的 GitHub Release 标记与随包报告为准；缺少任一项时只能发布候选版。

安装或升级前请安全退出客户端并保留备份。卸载程序不会删除用户数据或 Codex 登录目录。项目不包含自动更新和登录后自动启动；额度与任务发送仍受现有显式入队、真实来源及调度暂停保护。
