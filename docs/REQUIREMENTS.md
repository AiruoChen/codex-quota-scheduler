# 需求与当前范围

## 产品目标

在本人 Codex 订阅额度可用时，自动执行预先维护的有效任务，减少额度恢复后的空闲等待。
面向 Windows 本地运行，首版单账户、多项目、串行执行。

## 约束

- 五小时和周额度均以服务端返回为准，不能忽略其他阻塞额度。
- 已知重置时间仅用于安排查询，不能单凭时间认定已恢复。
- 默认保留 10% 额度，为可修改的提交阈值，不保证任务执行期间不超过阈值。
- 默认按优先级串行运行；以后再考虑多项目并发与隔离。
- 真实执行使用本人订阅登录，验证读取与执行账户一致。
- 任务内容、账户凭据与运行产物留在本地；SQLite、配置备份和个人文件不提交。
- 电脑关机或调度进程停止期间无法执行；唤醒后先核对当前状态。
- 桌面应用已有聊天的续接能力需实测，不作为本框架已支持的能力。

## 核心验收场景

额度恢复后按队列执行；周额度耗尽时等待；数据未知或过期时等待；重复刷新不重复启动；
登录失效时显示原因；程序重启不盲目重发；可暂停调度、取消运行并查看历史。
