# 安装包与数据迁移

日期：2026-10-26。客户端版本：0.3.0；当前数据库模式：7。
已实现 Windows x64 当前用户安装、手动升级、卸载保留数据，以及桌面备份、旧数据导入、恢复为独立副本和配置切换。
签名与稳定版门禁工具已在 [验收与发布](DESKTOP-ACCEPTANCE-RELEASE.md) 模块提供，但当前没有已验证的签名证书和干净机器验收结果；默认构建仍是未签名安装包。自动更新、开机启动及其他系统安装器属于后续增强。

## 安装与运行

运行 `CodexQuotaScheduler-0.3.0-win-x64-setup.exe`。安装器自带 Electron/Node/SQLite，无需另装 Node.js/npm；真实执行仍需用户自行配置 Codex CLI 和登录状态。
默认安装在当前用户的 `%LOCALAPPDATA%\Programs\CodexQuotaScheduler`，不申请管理员权限，不注册系统服务或开机项。
开始菜单入口必选，桌面快捷方式可选。安装完成后从开始菜单打开；首次默认空任务模拟环境，不提交真实任务。
开始菜单快捷方式写入与客户端一致的 AppUserModelID；实际系统通知仍受 Windows 权限和通知设置影响。

程序目录与 `%APPDATA%\CodexQuotaScheduler` 用户数据目录分离。便携目录仍可使用，不能只复制其中 EXE。
菜单“后台服务 → 安装与数据迁移…”打开数据管理区域，可查看当前用户数据目录、活动配置、客户端版本和支持的数据库模式。
点击“打开用户数据目录”可在系统文件管理器中打开当前实例的数据根目录，无需停止后台。

安装器不会关闭或强杀进程。发现同名客户端/后台进程或无法确认其状态时，安装与卸载均拒绝继续。
安装器持有维护互斥；安装版客户端在启动时检查它，避免安装期间启动新进程。便携版通过进程检查参与保护。
安装目录必须是独立的 CodexQuotaScheduler 文件夹；非空且无匹配产品标记的目录拒绝覆盖。安装器只删除生成清单中的程序文件，不递归清空目录。

## 旧项目导入

1. 在旧项目安全停止服务与调度，等待结果保存。遗留服务记录、未知进程和执行权按原恢复流程显式核对，不手动删除数据库。
2. 在桌面数据管理区域勾选操作范围确认，点击“停止自有后台并等待落盘”。外部服务须由所有者安全停止，或在原服务菜单中单独确认停止。
3. 点击“选择旧配置 / 备份并预检…”，选择旧项目的 JSON 配置文件。备份恢复时选择备份目录内的 `config.json`。
4. 核对来源、数据库、目标新副本、模拟/真实来源、数据库模式及任务/版本/运行数量，再点击“确认导入新副本并切换（不启动）”。
5. 完成后显式启动后台。队列保持暂停；检查项目路径、账户与待核对记录后，才能按原规则手动恢复派发。旧项目应保持停止，避免同时使用两份队列。

导入不合库、不覆盖当前默认配置、不改写源配置或源数据库。每次导入使用新的 `profiles/<UUID>/`，已有目标或失败暂存目录不覆盖。
源配置和任务清单的相对路径先按原位置解析；新的配置指向副本数据库与转换后的任务清单，项目、指令文件、Codex 可执行文件及 home 仍定位原位置。
不移动项目或 Codex 登录目录，不复制登录文件。任务版本、运行快照、输出、来源证据、事件、刷新去重和执行权记录均从一致性快照保留。
任意 CLI 参数内部的路径需用户核对，程序不会猜测参数含义并改写。
已初始化的数据库若不再需要原任务导入清单，可在清单缺失时从数据库继续迁移；清单存在但格式损坏仍拒绝。

预检只读打开现有数据库，校验产品、模式、完整性和活动进程，不创建空源库。
预览十分钟有效；提交前再次核对配置、任务清单和数据库逻辑指纹。来源发生变化时必须重新预检。
SQLite 使用只读连接、保留写锁及另一只读连接的 `VACUUM INTO` 生成一致性备份，包含已提交但尚未检查点的 WAL 数据；不直接复制活动数据库主文件。
转换只发生在独立暂存副本。完整语义检查通过且队列设置暂停后才发布副本，最后原子替换活动配置指针。
已死进程的遗留执行权原样保留，不能因复制或启动自动解锁、重发或批准请求。

## 备份与恢复

停止后台后点击“创建完整数据备份”。准备升级也会先等待后台落盘并创建备份，再退出。
备份目录包含：

```text
backups/<操作>-<UUID>/
  config.json             可独立导入的规范化配置
  state.sqlite            一致性数据库快照，转换前模式
  tasks.json              保留原路径语义的任务导入清单
  source-config.json      原始配置字节
  backup-manifest.json    时间、版本及每个文件的 SHA256，最后写入
```

备份包含私人任务、指令、输出和配置，仅保存于用户数据目录，不进入安装包或 Git，也不作为默认诊断导出。
恢复先校验清单和文件哈希，再按旧数据导入流程创建新副本；首版不提供原地覆盖恢复。
当前配置与每个已完成副本继续保留，可在“保留的数据配置”中选择并显式切换，切换不启动后台。
通知偏好仍使用原用户数据目录的桌面设置，不从旧项目复制通知历史或运行控制密钥。

迁移失败会保留备份、暂存目录和固定错误代码；活动配置不切换。中断留下的未完成备份没有完整清单，不能当作有效备份恢复。
数据库损坏、较新模式、较新客户端版本、数据管理记录损坏或数据库意外缺失时阻止继续，不重建空库。
启动、导入预检、切换及写入打开记录前均检查备份清单、导入副本的 profile.json 和已有 data-versions 记录。刚导入但尚未启动的副本也受版本保护；所需标记缺失或损坏时拒绝继续，保留数据库与活动指针。
活动指针损坏时保留原件，可在完全退出客户端后核对其 `.bak` 并人工恢复；失败暂存目录不会被自动清理。

## 手动升级与卸载

升级前选择“备份并安全退出，准备升级”，等待窗口退出后运行新安装包。安装器拒绝覆盖运行中的程序，也拒绝直接安装低于已安装记录的版本。
安装器只处理程序文件，不修改用户数据库。新版客户端首次打开旧数据时，先创建一致性备份，再运行原事务模式迁移和数据检查；当前模式的外部服务可以继续连接，但不会由客户端迁移。
模式迁移失败进入明确的人工恢复状态，备份路径可在数据管理区域查看。已有旧记录、执行权和审计不自动清理。
回退不能直接让旧程序写入较新模式，应使用匹配版本和匹配备份，并了解备份之后的记录不在副本中。

从 Windows 已安装应用或程序目录的 Uninstall.exe 卸载。默认且始终保留用户数据、备份、外部项目和 Codex 登录目录；未知程序目录文件也保留。
首版不在卸载器中提供删除私人数据操作。需要清理时应先验证备份，并由用户单独处理明确的数据目录。

## 构建与验收

```powershell
npm.cmd run package:installer
# 已有新构建便携目录时，避免再次生成同名目录：
node scripts/package-installer.mjs --package .release/desktop/CodexQuotaScheduler-win32-x64 --output-name installer
node --experimental-sqlite scripts/smoke-installer.mjs --package .release/desktop/CodexQuotaScheduler-win32-x64
```

构建输出 `.release/installer/` 中的 EXE、`.sha256` 和 `release.json`。清单记录版本、编译器、未签名状态和程序文件哈希；不会覆盖既有安装包，重复构建需选择新的输出名。
构建器下载固定 NSIS 3.12 维护分发，每次校验归档 SHA256 并重新解压，不安装全局工具；只打包当前源码派生的运行文件白名单。
可通过 `Get-FileHash <安装包路径> -Algorithm SHA256` 与 `.sha256` 对比完整性；校验和不能替代发布者签名。

自动验收覆盖原件字节不变、WAL 数据、任务版本和快照、活动/未知进程、过期预览、目标冲突、损坏/较新模式、失败记录、备份校验、恢复及版本升级。
Windows 安装验收使用独立产品标识、项目内目标及专属测试注册项/快捷方式，实际经过安装、原生配置选择、导入、切换、升级准备、重新安装和卸载。
原有桌面 GUI、托盘和七个生命周期场景继续回归，新增升级准备场景，共八个。测试安装包使用独立产品标识、固化的隔离目标和较快的 zlib 压缩；正式包使用 LZMA，两者共用安装脚本及文件校验流程。所有任务数据为模拟或本机协议替身，没有提交真实账户任务。
本机隔离 PATH 验收不等于干净 Windows 虚拟机、正式签名发布、断电演练或长期运行验收。

依据：[NSIS 文档](https://nsis.sourceforge.io/Docs/Chapter4.html)、[维护编译器与哈希](https://github.com/electron-userland/electron-builder-binaries/releases/tag/nsis%402.0.1)、[SQLite VACUUM INTO](https://www.sqlite.org/lang_vacuum.html)、[Node.js 22.12 SQLite](https://nodejs.org/download/release/v22.12.0/docs/api/sqlite.html)。
