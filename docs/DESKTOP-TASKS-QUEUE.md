# 任务管理与调度队列

本模块接在 GUI 基础框架之后，复用既有任务仓储、不可变快照和串行调度。

## 维护任务

任务页按名称、ID 或项目目录搜索，可筛选启用/停用状态，每页 25 项。
筛选与分页由 SQLite 参数化查询完成，不把指令正文放入列表响应；归档任务不出现在列表中。

新建/编辑使用宽编辑区，后台自动生成稳定 UUID，创建请求持久化去重；普通用户只填名称。模型及推理强度由 Codex 动态目录读取，官方项目／会话按真实 ID 二级选择，不以文件夹冒充项目。

续接默认按“全部会话（不按项目过滤）”读取名称。官方项目存在但会话 `projectId` 为空时，选项目可能返回空列表；会话栏明确解释并提供“查看全部会话”。空关联和字段缺失分别标注，不以目录猜测官方项目。会话加载、错误、重试和分页均有独立提示；切换项目后清除旧环境并拒绝过期响应。
默认只读，工作区写入会明确显示允许修改的目录。保存只产生定义版本，不执行任务。
本地文件夹模式提供目录选择器；官方项目由用户确认本次工作目录和可写范围，无项目只读模式使用管理工作区。已有原生会话只读展示实际目录，完整有效权限未知时保存执行被阻断，详见 [实施说明](IMPLEMENTATION-0.4.0.md)。

列表提供创建时间倒序／正序，默认最新优先；服务端先排序再分页，同一时刻按 ID 稳定排序。编辑不改变创建时间，排序偏好按本地配置范围记忆，不改变队列派发顺序。

编辑期间若其他客户端或 CLI 修改任务，保存报告 TASK_CONFLICT，原草稿和旧 revision 保留，不自动覆盖或改为新建。
“重新加载服务器版本”会先确认放弃未保存草稿，再加载最新定义。关闭客户端不会把草稿写入浏览器存储。
启停也使用 revision 检查并产生新版本；归档保留历史与运行快照，未领取记录由后台跳过，当前运行不因归档而被宣称取消。

## 预览与入队

“加入队列”和“执行”先读取完整任务，预览版本、解析后的项目目录、权限、优先级、模型/会话和指令。
确认提交携带 revision；仓储在创建快照的同一同步事务内校验，期间的修改不会被悄悄带入。
同一任务版本重复入队返回既有运行 ID，包括已移除或已结束的版本；如需新的运行快照，应编辑并保存新版本。
模拟来源允许保存及入队体验，但真实执行、启动真实调度和恢复派发仍由后台拒绝。

## 调度队列

队列显示快照名称、项目、版本、优先级、准确入队序号、时间和状态，并标明当前定义已停用或归档。
可按任务/项目和状态筛选，每页显示 25 项；按快照优先级降序、同优先级按入队序号展示，实际领取以后台判定为准。
队列筛选目前在收到的状态列表中完成；尚未声称完成超大队列的网络传输基准。

后台最近判定直接来自调度事件，显示等待额度、等待已确认刷新、执行权占用、空队列等原因；外部调度无法提供该进程事件时明确等待判定。
“启动调度进程”后保持暂停；“恢复派发”需确认；“暂停派发”只阻止领取下一项；“停止调度进程”单独确认并请求取消当前执行、等待落盘。
“移除”取消未领取的安排，或将已结束记录从队列隐藏，并保留不可变快照、运行历史与版本去重。待人工核对记录需点击“移除并解除阻塞”并明确确认；原状态仍为待核对，派发保持暂停，只有人工恢复后才继续。运行中或仍持有执行权的记录不能移除，需先请求取消并等待终态；事务会重验当前状态。详见[队列移除与详细诊断](QUEUE-AND-DIAGNOSTICS.md)。
结果不明仍须到异常处理核对，界面不自动重发、解锁、批准审批或恢复派发。

## 目录选择安全

管理窗口新增的隔离 preload 只暴露 `desktopProject.chooseDirectory()`，没有文件读写、任意参数、通用 IPC 或后台控制密钥。
Electron 适配器验证准确窗口、主 frame、当前验证过的管理地址，并在选择结束后重验来源；取消或来源变化不返回路径。
只允许一个目录选择窗口，主进程使用固定的 openDirectory 选项；业务写请求继续通过 HTTP 会话和 CSRF。
参考 [Electron dialog](https://www.electronjs.org/docs/latest/api/dialog) 和本项目锁定版本的类型定义。

## 验收

运行 `npm.cmd run check`、`npm.cmd test`、`npm.cmd run demo`，再顺序运行打包版 `smoke-desktop.mjs` 与 `smoke-lifecycle.mjs`。
任务/队列 GUI 验收覆盖搜索、并发编辑草稿保留、预览后版本冲突、重复入队和旧正文快照保留；目录选择的拒绝参数、来源变更、并发及取消使用可注入替身验证。
1000 条任务的筛选分页在本机独立测试中约 3.4 ms；这不是所有设备的性能保证。原生目录选择的系统交互仍建议人工验收。
全部自动化只使用临时配置与模拟/协议替身，没有真实账户任务。
本轮严格检查、213 项回归、模拟演示、打包版 GUI 与六个生命周期场景通过，0 页面脚本异常。
