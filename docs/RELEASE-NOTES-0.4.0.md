# Codex Quota Scheduler 0.4.0 版本说明

日期：2026-10-28。发布状态：Windows x64 测试客户端。0.4.0 编号对应当前已交付功能，稳定版签名、真实任务及长期人工验收仍待补证据；下载附件以 GitHub Releases 实际状态为准。

## 本版内容

- 新建任务自动生成 ID，按 Codex 目录动态选择模型、推理强度、项目及会话；分页、重试和来源变化有独立处理。
- 已验证的桌面旧项目关联采用只读兼容，无法确认归属时可查看全部会话，不按目录猜测项目。
- 续接自动读取并展示实际目录，可为本次任务明确授权读取范围及精确写入目录；执行前核对账户、来源、CLI、策略和实际权限。
- 任务列表默认新任务在前，可切换时间顺序并保存偏好；五小时及周额度保留线分别设置。
- 额度中断续接默认关闭。明确开启后，仅在准确额度失败、完整耗尽证据和服务端窗口重置均成立时，创建独立子运行，追加原始指令快照及“请继续这个被截断的任务”。
- 完整额度读数兼容同一刷新边界的一秒差异；保留历史边界、过期和缺失窗口保护，不凭本地计时认定恢复。
- 队列支持逻辑移除。待核对记录经人工确认后可移除并解除该项阻塞，历史和原未知状态保留，派发保持暂停。
- 缺少准确来源／会话／回合时禁用应用远端结果；详细脱敏诊断可查看、复制和下载，旧版未保存的响应无法补回。
- 核对准确 CLI 协议后可在本回合清除继承的环境选择，目录、网络、审批和临时目录校验继续保留。
- 保留六页 GUI、后台生命周期、托盘与通知、备份导入、安装升级和已有审计修复。Windows 测试限制文件并发，保留全部用例及原超时门槛。

## 从 0.3.0 升级

1. 保持派发暂停，安全停止旧后台并退出旧客户端，保留有效备份。
2. 使用匹配 0.4.0 的安装包或完整便携目录；便携版不能只替换 exe。客户端不会自动更新。
3. 核对任务、运行历史、队列及已保存／当前生效配置。数据库保留原数据，模式 10 包含队列移除标记；本次版本号调整不新增数据库迁移。
4. 核对待人工处理记录，按需移除或确认解除阻塞，再决定是否恢复派发。更新不会恢复或重发旧任务。

旧客户端可能拒绝新版本配置或较新数据库。需要回退时保留现有数据，并使用升级前的有效备份及匹配版本；不要清库或篡改版本标记。

## 范围与验证

完整继承原会话权限、零文件夹官方项目及跨设备／远程环境仍有限制。明确授权模式固定关闭网络，审批请求不会自动同意；读取范围须按界面说明确认。真实恢复／发送、独立 Windows、签名、原生通知／缩放／故障人工走查和连续 24 小时实测继续按发布门禁记录。

本次审计范围和回归证据见[0.4.0 代码审计](AUDIT-0.4.0.md)。候选包须绑定通过检查的准确源码提交、安装器 SHA256 和验收报告；版本号本身不替代这些证据。完整操作见[用户手册](USER-MANUAL.md)。
