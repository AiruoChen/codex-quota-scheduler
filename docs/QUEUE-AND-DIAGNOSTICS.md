# 队列移除与详细诊断

日期：2026-10-28。

## environment_selected 是什么

这个检查项表示恢复响应保留了环境选择，旧实现会直接阻断。非空列表本身不能证明该环境属于远程。本次修复在核对准确已配置 CLI 的版本和生成协议后，确认 `turn/start environments: []` 明确禁用环境访问，再清除本回合选择。目录、可写根、临时目录、网络和审批仍按本次授权逐项核验。未知协议、异常结构或权限不一致继续阻断。

旧运行没有保存当时完整响应，不能还原所选环境的内容或保证这是唯一失败项。维护检查不恢复、不重发原任务。

## 移除卡住的队列记录

1. 保持派发暂停，查看运行详情和官方会话，核对是否已经执行。
2. 未领取记录点击“移除”；待核对记录点击“移除并解除阻塞”，阅读提示后明确确认。
3. 记录从队列隐藏，但运行详情、原快照、输出、待核对状态和去重记录都保留，不会被改成成功或已取消。
4. 检查其余待核对记录。全部处理完后，需要用户手动恢复派发。

运行中或仍持有执行权的记录不能移除。应先请求取消，等待准确回合终态；本地遗留执行权只能按异常恢复流程显式核对处理。

移除不会产生重试。同任务同版本再次入队仍返回原记录；需要新安排时应编辑并保存新版本、重新预览后入队。

此次数据库迁移保留旧记录并增加队列移除标记。升级前保留备份；旧客户端可能拒绝读取新版数据库，不要用旧客户端覆盖新版数据。

## 为什么应用已确认结果不可用

该操作需要已记录来源、准确会话和准确回合，才能只读查询并应用远端已确认终态。没有准确回合时，按钮禁用且后台拒绝操作；不能通过猜测最新回合解除阻塞。人工核对后，可以确认解除阻塞或从队列移除，原未知状态和历史继续保留。

## 获取更详细的错误日志

打开“运行记录 → 查看详情 → 详细诊断日志（脱敏）”，点击“查看／刷新详细诊断”“复制诊断日志”或“下载诊断 JSON”。

诊断包含运行状态、是否记录发送开始和准确回合、执行阶段、CLI 版本、请求与响应顺序、相对耗时、授权期望值和实际权限结构、固定错误码及失败检查项。路径、会话和环境替换为仅在该次运行内可对照的代号。

不会保存或导出凭据、原始错误全文、任务指令、输出内容和完整私人路径。真实执行输出仍可在运行详情中查看与复制。提供诊断前可先打开 JSON 检查内容。

新时间线从更新后新运行开始记录，数量有上限并标记截断。旧版未保存的响应不能补回；连接前失败也可能没有 RPC 时间线，此时查看执行阶段和固定系统错误码。没有时间线不等于任务已经发送或未发送，仍应结合持久化发送证据和准确回合核对。
